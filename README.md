# NeuroAI Take-Home Assignment 4 - Spiking neural networks

| File | Content |
|---|---|
| `snn_mnist_experiments.ipynb` | Question 2: Brian2 feed-forward SNN on Poisson-encoded MNIST, baseline + tweaks (tau_m sweep, sparse connectivity, homeostasis), plots and analysis (executed, outputs included) |
| `snn_mnist.py` | The same model code as an importable module |
| `report/report.tex` | Report (Question 1 design answers + Question 2 results); copy into Overleaf together with `report/figures/` |
| `figures/` | Figures generated by the notebook |
| `results/results.json` | All numbers reported in the notebook / report |
| `data/` | MNIST IDX files (downloaded from the PyTorch mirror) |

## Running
```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=-1 snn_mnist_experiments.ipynb
```
Full execution takes about 40 minutes on a laptop (pure-numpy Brian2 backend, no compiler needed).
